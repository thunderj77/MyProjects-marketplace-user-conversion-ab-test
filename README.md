## 📌 Описание проекта

Маркетплейс столкнулся с падением конверсии при растущем трафике. Задача – провести комплексный аудит продукта, выявить точки отказа и предложить решения. Особый фокус – канал TikTok с отрицательной рентабельностью (ROI -91%).

### Ключевые задачи

1. Оценка динамики MAU, выручки, конверсии, AOV, CAC
2. Расчёт юнит-экономики (LTV, CAC, ROI, Payback Period)
3. Когортный анализ ROI для выявления «точки перелома»
4. RFM-сегментация пользователей
5. Анализ воронки конверсии по сегментам
6. A/B-тест: влияние бонуса на первую покупку (TikTok)

### Гипотеза A/B-теста

- **H₀:** Бонус не влияет на конверсию TikTok (CR_treatment ≤ CR_control)
- **H₁:** Бонус увеличивает конверсию (CR_treatment > CR_control)

**Параметры теста**

| Параметр | Значение |
|----------|----------|
| Уровень значимости (α) | 0.05 |
| Целевая аудитория | Новые пользователи TikTok |
| Группы | Control (без бонуса) / Treatment (с бонусом) |
| Основная метрика | Конверсия в первую покупку |
| Барьерная метрика | AOV (средний чек) |

## 🔍 Ход работы

### 1. Анализ ключевых метрик
- Построена динамика MAU, выручки, конверсии, AOV, CAC за 2024 год.
- **Выявлена точка перелома – апрель/май 2024:** конверсия упала с 43% → 24%, выручка сократилась на 45% при стабильном MAU.

### 2. Юнит-экономика и когорты
- LTV = 497 ₽, CAC = 401 ₽, ROI = +20%, Payback Period = 9.7 мес.
- Построена когортная «лесенка» ROI – когорты сентябрь–декабрь убыточны (ROI от -21% до -79%).

### 3. Сегментация и поиск инсайтов
- **RFM-сегменты:** regular (18% аудитории → 67% выручки), one_time (15% аудитории → 1% выручки)
- **Каналы:** Affiliate ROI +235%, SEO +189%, TikTok ROI -91%
- **Воронка:** критическая потеря на этапе `add_to_cart → checkout_start` (60-90% пользователей)

### 4. A/B-тест (бонус для TikTok)
- Рассчитаны конверсии, ARPU, ARPPU, AOV по группам
- Проведён **Z-тест для пропорций** и **t-тест Уэлча** (ARPU, ARPPU, AOV)
- Выполнен **Power Analysis** (MDE = 9.19 п.п.)

### 5. Валидация теста
- Равенство групп проверено через распределение пользователей
- A/A-тест не проводился (дизайн эксперимента – сплит-роллинг от смежных аналитиков)

## 📊 Результаты A/B-теста

| Показатель | Контроль (A) | Тест (B) | Изменение |
|------------|--------------|----------|------------|
| Конверсия (CR) | 1.06% | 7.51% | **+609%** |
| ARPU | 252 ₽ | 2 625 ₽ | **×10.4** |
| ARPPU | 23 648 ₽ | 34 960 ₽ | **+48% (p=0.025)** |
| AOV | 15 766 ₽ | 16 648 ₽ | стабилен (p=0.394) |
| p-value (CR) | – | – | **< 0.0001** |

### Power Analysis
- MDE = 9.19 п.п. (при power=80%, α=0.05)
- Фактический эффект = 6.45 п.п. (1.06% → 7.51%)
- Несмотря на эффект ниже MDE, p-value < 0.0001 позволяет считать результат надёжным

## 💡 Выводы и рекомендации

### Основные инсайты

✅ **Юнит-экономика устойчива** – LTV > CAC, ROI +20%  
⚠️ **Продукт сломался после апреля 2024** – падение конверсии и удержания  
🔴 **Ключевая точка оттока** – `add_to_cart → checkout_start` (потеря 60-90%)  
📉 **Убыточные каналы** – TikTok (ROI -91%) требует изменения оффера или отключения  

### Рекомендации

| Приоритет | Рекомендация | Ожидаемый эффект |
|-----------|--------------|------------------|
| 🔴 High | **Внедрить бонус на первую покупку для TikTok** | CR с 1% → ~7-8% |
| 🔴 High | Оптимизировать этап `add_to_cart → checkout_start` | Снижение оттока в воронке |
| 🟠 Medium | Перераспределить бюджет с TikTok → Affiliate/SEO | Рост общего ROI |
| 🟠 Medium | Стимулировать second purchase для `one_time` | Рост LTV сегмента |
| 🟡 Low | Локальная адаптация для Новосибирска/Ростова | Выравнивание региональной конверсии |

### Зоны роста для следующих A/B-тестов

1. **Протестировать разные размеры бонуса** – найти оптимальную точку по ROMI
2. **Оценить LTV когорт с бонусом** – нет ли «отвала» после первой покупки
3. **Протестировать бонус на других каналах с низкой CR** (например, Google Ads)
